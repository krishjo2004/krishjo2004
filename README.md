# Doctor Appointment Booking System

## Project Description

This is a web-based Doctor Appointment Booking System developed using Flask and SQLite. The system allows patients to book appointments, view bookings, and delete appointments.

## Features

* Book doctor appointment
* Prevent double booking
* View all appointments
* Delete appointments
* SQLite database
* Flask backend
* HTML frontend

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS

## Setup Instructions

1. Install Python
2. Install Flask:

   ```
   pip install flask
   ```
3. Open project folder:

   ```
   cd doctor_appointment_system
   ```
4. Run the application:

   ```
   python app.py
   ```
5. Open browser:

   ```
   http://127.0.0.1:5000
   ```
